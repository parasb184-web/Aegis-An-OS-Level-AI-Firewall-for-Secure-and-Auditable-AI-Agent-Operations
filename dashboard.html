Only 0, 30, 40 and 70 are reachable, which is why the warn threshold is 30: it is the one score that can land between allowed and blocked.
If the daemon stops?Aegis fails open. When the daemon is gone the kernel stops asking it, so files that would be refused are simply opened, and nothing is recorded. Measured: after kill -9, the 35th read of an SSH key succeeded. files are allowed, nothing recorded
